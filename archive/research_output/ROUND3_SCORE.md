# Round 3 — SCORE (Survivors Rated 0-5 Scale)

Scoring dimensions (each 0-5, higher = better for this profile):
- CAPITAL EFFICIENCY: How much of P10k is needed as % of capital? 5 = <10% (≤1k), 4 = <20% (≤2k), 3 = <40% (≤4k), 2 = <60% (≤6k), 1 = <80% (≤8k), 0 = near/max limit
- SKILL MATCH: How well does it match a solo web developer's skills (coding, design, digital)? 5 = direct web/code/design use, 4 = closely related (digital marketing, templates), 3 = transferable (writing, tutoring), 2 = different but learnable fast, 1 = unrelated, 0 = physical/manual only
- SPACE FIT: How well does it fit a small house with ~5-10 sqm workspace? 5 = laptop only, 4 = laptop + shelf, 3 = laptop + small storage box, 2 = needs dedicated corner + storage, 1 = needs significant floor space, 0 = needs garage/workshop
- CONNECTION INDEPENDENCE: Can it start with zero existing network? 5 = fully platform/self-driven, 4 = platforms + cold outreach, 3 = local flyers + platforms, 2 = needs referrals/network, 1 = needs connections to clients, 0 = impossible without network
- REVENUE VELOCITY: Days to first cash / consistent cash flow speed. 5 = <7 days, 4 = 7-14 days, 3 = 14-30 days, 2 = 30-60 days, 1 = 60-90 days, 0 = >90 days / speculative
