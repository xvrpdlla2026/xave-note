Appearance

Surfaces and the accent change together · each palette has its own dark variant.

Storage

Your notes live in a SQLite database held in this browser. It is written to IndexedDB automatically after every change. There is no save button, and nothing leaves your machine.

Export & migration

The export is the database itself, byte for byte. Open it with sqlite3, DB Browser for SQLite, or any other SQLite tool.

Security

Note bodies and stored file contents are encrypted with your password. Everything else stays readable: note titles, file names, folder names, dates and sizes are not encrypted, which is what still lets you browse and search this notebook. This protects the stored database — the copy in this browser and any .db file you export — and nothing more: it does not protect a session you have already unlocked on a machine someone else can use, and it cannot protect you from malware on that machine. The browser keeps its own copies of this database as it rewrites it, and reclaims them on its own schedule, so an earlier unencrypted copy may remain on this device until it does. The password is not stored anywhere. If you forget it, the encrypted note bodies and files cannot be recovered.

Danger zone

Erases every workspace in this browser. Export a copy first.
